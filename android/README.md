# ش ك م Android app

Lightweight Android WebView wrapper for the SHKM clinic website.

- Application ID: `com.shkm.clinic`
- App name: ش ك م
- Website: https://kick-player.vercel.app
- Build workflow: `.github/workflows/build-android-apk.yml`

The workflow builds a debug APK and uploads it as the `SHKM-Android-APK` artifact.
An internet connection is required to load the website.
